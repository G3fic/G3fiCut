# GifCut v0.3.79 — Builder Decisions Supplement

**Status:** Proposed defaults for the parent design  
**Parent:** [Multimedia Editing Workspace Design](2026-11-01-editor-v0.3.79-design.md)

The design review was performed as a fresh implementer reading the specification without relying on the discussion. The following defaults close the implementation questions that would otherwise force guesses.

## Import and placement

- Importing through the picker or dropping files from Explorer registers assets in the Media library only; it does not insert a batch into the sequence unexpectedly.
- Dragging an asset card from the library to a track creates the timeline item at the drop time. Double-clicking a video/image/audio card appends it to the end of the first compatible visible track as a convenience.
- Duplicate paths are deduplicated after absolute-path normalization. A mixed drop imports all supported items and reports each unsupported item separately.
- Still images and new text clips default to five seconds. Video/audio clips use their probed source duration unless the user trims them.
- If a media file later goes missing, the project retains the asset and timeline references and marks it for relinking.

## Timeline and audio

- Default track order from bottom to top is V1, additional video tracks, image/overlay tracks, text/title tracks; audio tracks appear below the visual tracks. Users can reorder tracks.
- Visual track order is also the default z-order: a higher visual track renders above a lower one.
- Video source audio remains enabled at its current/default gain unless the user mutes that video track or changes its gain. Imported audio tracks are mixed with enabled video source audio. Do not automatically replace source audio when an external track is added.
- Inserted audio clips land at their drop position; double-click append uses the end of the longest existing audio clip.
- A project timeline with no visual item still opens normally, but preview remains black until a visual clip is active.

## Text and preview

- New text uses the platform's regular sans-serif fallback, white fill, centered alignment, and a five-second duration. User text is stored as plain project data; rendering for export must use safe text rasterization, not raw command interpolation.
- Project canvas background defaults to black. “Размытие исходного видео” is opt-in and affects only the canvas surround/fill, not the clip's Blur effect.
- The effects/transition library preview uses a frame from the current project when available; otherwise it uses locally bundled, redistributable sample imagery. It must not download sample media at runtime.

## Effects and transitions

- Clicking a library card selects the preset and opens its inspector. Selection never inserts an item. The inspector's explicit Add action creates exactly one timeline item.
- Effects are applied only over the selected time interval. A transition is attached to a valid adjacent video cut and is disabled with an explanatory message when no valid cut exists.
- When a timeline effect or transition is selected, the inspector edits that placed instance; it does not jump back to a different library selection.

## Release

- Use `0.3.79+87`, show `GifCut v0.3.79` in the window/application title and header, and wait for a successful Windows Actions build before creating/publishing the release tag.
