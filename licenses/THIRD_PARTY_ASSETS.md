# Third-party creative assets

## Cinematic LUT pack by slaycamera

GifCut downloads and bundles the five original 3D LUTs from
[slaycamera/luts](https://github.com/slaycamera/luts) during the Windows
release build:

- `slay-01-amber.cube` — Amber
- `slay-02-fade.cube` — Fade
- `slay-03-neon.cube` — Neon
- `slay-04-film.cube` — Film
- `slay-05-portrait.cube` — Portrait

GifCut's Windows workflow downloads the files from the upstream repository and
places them in the application's `luts/` folder. The files are included in both
the installer and portable Windows archive.
